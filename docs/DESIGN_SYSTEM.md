# Dayflow Design System

Dayflow uses a deep navy workspace (`#0e1c2f`), a warm neutral canvas (`#f6f7f4`), and an electric lime action accent (`#c7f36b`). Space Grotesk provides display hierarchy while DM Sans carries dense operational copy. Cards use soft borders, generous radius, and restrained shadows. Lime means actionable or healthy; amber means attention; blue means contextual; coral means rejection or risk.
