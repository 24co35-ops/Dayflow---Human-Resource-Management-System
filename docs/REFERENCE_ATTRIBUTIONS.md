# Dayflow Reference Attributions

Dayflow uses the FastAPI full-stack template as its foundation and draws architecture patterns from Bulletproof React. Domain vocabulary is informed by Frappe HRMS. UI primitives and implementation patterns reference shadcn/ui, Lucide, TanStack Table, Recharts, React Hook Form, Zod, Zustand, Supabase JS, and React Router. Each project remains separately licensed and should be reviewed before redistribution.
