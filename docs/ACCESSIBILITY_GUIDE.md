# Dayflow Accessibility Guide

Dayflow keeps every high-impact action keyboard reachable, visibly focused, and understandable without relying on color alone. Status dots are paired with text, approval actions have labels, and charts include text summaries. Reduced-motion users receive the same information without decorative transitions. Before judging, test the sidebar, Flow composer, leave form, and Kanban actions using Tab, Enter, and Escape only.
